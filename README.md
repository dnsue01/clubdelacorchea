# El Club de la Corchea

Web del podcast de música urbana presentado por Bumbum, Cypher y Valentino. Reúne los últimos episodios, presenta a las voces del programa y ofrece un canal de contacto.

[Visitar la web](https://dnsue01.github.io/clubdelacorchea/)

## En el repositorio

La web usa HTML, CSS y JavaScript. Para servirla en local, ejecuta `node server.mjs` desde la raíz y abre `http://localhost:4173`.
